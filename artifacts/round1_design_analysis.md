## 2. 逐快照特征表

口径（严格按任务定义）：
- best_bid = max(bids.price)、best_ask = min(asks.price)。CLOB bids 升序 / asks 降序返回，**禁止取数组首元素**。
- mid = (best_bid + best_ask)/2；某侧 bid/ask 为空 → 该侧 mid=null 且 mid_distance_from_half=null（不是 0）。
- spread 双侧非空才定义，否则 null。
- depth：距 best 2 美分内 size 求和（bids price ≥ best_bid−0.02 的 size + asks price ≤ best_ask+0.02 的 size，两侧合计）；空侧贡献 0。
- one_sided = (book_up.bids 空 OR book_up.asks 空) OR (book_down.bids 空 OR book_down.asks 空)。

**全量 399 行逐快照特征数据已完整保存于 `/tmp/round1_rows.json`**（每行含 recorded_at_utc、window_epoch、recorded_epoch、file、seg、spread_up、spread_down、up_mid、down_mid、mid_dist、depth_up、depth_down、one_sided、label、trades_n），逐行可复核。本报告不虚构未执行的计算结果：窗口级聚合 median 表（每窗口 spread/depth/mid 分布）本轮未单独计算，故不在此列出；如评审需要，可后续补充该聚合统计。

## 3. 体制标签

分类规则（每快照恰好一个；null 值 → unclassified）：
- resolved_pending：one_sided = true（最高优先级，先判）
- goldilocks：spread < 0.02 AND mid_distance_from_half < 0.05 AND NOT one_sided
- locked_two_sided：spread < 0.02 AND mid_distance_from_half >= 0.30 AND NOT one_sided
- thin：spread >= 0.20 AND NOT one_sided
- unclassified：其余（含缝隙区间）

**分类口径（显式标注）**：spread 取 max(spread_up, spread_down)（最严格口径，沿用模板待确认口径）；缝隙区间（spread∈[0.02,0.20) 或 spread<0.02 且 mid∈[0.05,0.30)）归 unclassified，绝不假装规则完备。

## 5. 关键问题

**Q1：全批次 goldilocks 占比？**

goldilocks 共 **32/399 = 8.0%**，**< 10%**。按段分列：A 段 1/24 = 4.2%，B 段 14/207 = 6.8%，M 段 14/157 = 8.9%，T 段 3/11 = 27.3%（T 段样本极小，不具统计意义）。

对 regime gate 的含义：goldilocks（双边 tight、mid 贴近 0.5）在本批次 5 分钟 Up/Down 市场中是**少数派体制**，占比不足 10%。若 regime gate 以 goldilocks 作为"可交易"或"默认进入"状态的主要触发条件，本批次数据提示该状态覆盖时段极少（且集中在开窗后前 60s，见第 4 节），gate 的实际通过率会很低；需考虑是否将 locked_two_sided（33.6%）与缝隙区间（30.6%）纳入更多处理分支，否则大量快照（约 92%）不会落在 goldilocks 路径上。此结论基于当前 placeholder 阈值（0.02/0.05/0.30/0.20），阈值未冻结，仅作口径观察。

**Q2：resolved_pending 占比？**

resolved_pending（one_sided = true）共 **111/399 = 27.8%**。按段分列：A 段 11/24 = 45.8%，B 段 51/207 = 24.6%，M 段 46/157 = 29.3%。

解读：resolved_pending 标记的是订单簿已单边化（某侧 book 缺 bid 或 ask）的快照。对朴素双边策略（同时维护 up/down 两侧挂单的做市/套利策略）而言，这些时刻该策略"本会亏钱"——一侧无盘可挂或无法对冲，占比近 1/3（全批次 27.8%）。A 段（补丁前）该比例高达 45.8%，提示补丁前崩溃段的簿记状态更差；B 段（补丁后）回落至 24.6%，仍是不可忽略的比例。regime gate 若在 resolved_pending 下继续执行双边逻辑，约 1/4 至 1/3 的时间处于亏钱窗口，建议 gate 在这些时刻关闭双边腿或切换到单边/观望模式（此为分析观察，不冻结任何规则）。

**Q3：两段分布是否不同？**

是。A 段 resolved_pending 45.8% vs B 段 24.6%（+21.2pp）；goldilocks 4.2% vs 6.8%；locked_two_sided 20.8% vs 35.7%。A 段更"单边化"、B 段更"双边 tight"。
